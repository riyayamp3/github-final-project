# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based project that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal: The initial amount of money.
- Rate: The annual rate of interest in percentage.
- Time: The time period in years.

## Output

The calculator displays the simple interest calculated from the provided values.

## Example

Principal = 1000

Rate = 5%

Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100
